# 运营系统 UI 设计（导航栏 / AI 对话框 / 工作区 三段）

> 说明：管理系统的「导航栏 / AI 对话框 / 工作区」三段式 AI 助手 UI **已实现**；本设计是**运营系统 UI**，沿用同一三段范式，但内容面向运营域。
> 运营域结构沿用《运营系统导航预览》：顶部「视频运营 / 电商运营」Tab 切左导航，下方固定通用功能栏。
> 引擎对齐：《AI底座全量改进详细设计》（Orchestrator graph 模式 + SSE 事件）。

---

## 一、设计原则

| 原则 | 含义 |
|---|---|
| 复用三段范式 | 与管理系统 AI 助手一致：导航栏=上下文、AI对话框=任务入口、工作区=执行面 |
| 运营域导航 | 导航栏承载运营双板域导航（视频/电商）+ 固定通用栏，不是通用账号条 |
| AI 执行范式 | 用户只抛运营任务（如"做五粮液短视频挂车"），AI 调工具直接执行 |
| 工作区=运营总览+任务标签 | 默认进入即展示**运营数据总览**（无需开任何页面）；执行任务时开启**新页签直接覆盖**，多任务以标签切换 |

---

## 二、第 1 段：导航栏（运营域导航 · 明细）

**角色**：运营域上下文切换 + 通用功能常驻。顶部 Tab 仅切左导航，通用栏固定不切。`导航栏是真实功能菜单，不是摆设`——每个目录均可点击进入对应模块页；每个目录右侧 `@AI` 把该域任务丢给 AI（映射对应 ops 工具）。

### 2.1 顶部 Tab（仅切换下方左导航）

| Tab | 含义 |
|---|---|
| `视频运营` | 短视频内容生产 + 直播 + 投放 + 私域 + 达人 + 出海 全链路 |
| `电商运营` | 选品 + 商品 + 订单 + 财务 + 客服 + 归因 + 复盘 经营链路 |

### 2.2 短视频运营 · 左导航（分组 → 功能目录）

| 分组 | 功能目录（可点击进入） | 目录说明 | @AI 映射工具 |
|---|---|---|---|
| **内容创作** | 市场情报、人性洞察、选题中心、脚本工坊、素材中心、智能成片 | 热点→洞察→选题→脚本→素材→成片 全流程 | `ops.topic.*` `ops.script.*` `ops.video.*` |
| **发布分发** | 发布管理(草稿/定时/多平台)、挂车管理(商品关联)、分发记录 | 发抖音/快手等 + 商品挂车 | `ops.distribute.*` |
| **直播运营** | 直播中控(开播/大屏)、话术库(话术推送)、助播机器人、直播复盘 | 直播全流程 + AI 实时助播 | `ops.live.*` |
| **流量投放** | 投流计划(生成/管理)、投放监控(消耗/ROI)、预算中心 | 千川/信息流投放与控本 | `ops.boost.*` |
| **粉丝私域** | 粉丝画像、私信管理、社群运营、粉丝分层 | 私域沉淀与触达 | `ops.private.*` |
| **达人合作** | 达人库、商单管理(撮合/执行)、效果追踪 | 达人商单全流程 | `ops.kol.*` |
| **内容出海** | 多语翻译、海外平台、出海数据 | 内容跨语言/跨平台出海 | `ops.global.*` |

> 短视频运营 = 7 大分组 / 22+ 功能目录，覆盖"内容→发布→直播→投放→私域→达人→出海"（账号矩阵为跨域资产，见 2.4 固定通用栏）。

### 2.3 电商运营 · 左导航（分组 → 功能目录）

| 分组 | 功能目录（可点击进入） | 目录说明 | @AI 映射工具 |
|---|---|---|---|
| **选品管理** | 选品中心(推荐/决策)、爆款挖掘、利润测算、供应链 | 选品到供应链全链路 | `ops.select.*` |
| **商品管理** | 商品内容(图文/详情生成)、商品库、价格管理、SKU 管理 | 商品信息与上架 | `ops.product.*` |
| **订单履约** | 订单中心、物流跟踪、打单发货、售后管理 | 下单到履约到售后 | `ops.order.*` |
| **收益财务** | 收益对账、账单中心、差异处理(高风险) | 营收核对与差异处置 | `ops.recon.*` |
| **客户服务** | 智能客服、客诉管理、高风客诉(高风险)、评价管理 | 售前售后客服与风控 | `ops.cs.*` |
| **效果归因** | 投放归因、转化分析、ROI 分析 | 渠道与转化效果度量 | `ops.insight.*` |
| **复盘优化** | 周期复盘、策略库、优化建议 | 经营复盘与策略沉淀 | `ops.review.*` |

> 电商运营 = 7 大分组 / 20+ 功能目录，覆盖"选品→商品→订单→财务→客服→归因→复盘"。

### 2.4 固定通用栏（融合后 · 不随 Tab 切换）

> 融合原则：按「业务域 / AI 能力域 / 平台管理域 / 用户域」归类，把 10 个平铺一级项收敛为 4 个一级类目，避免过长；每个类目下挂原功能为子项。

| 一级类目 | 融合的原功能 | 子功能（点击进入） | 说明 |
|---|---|---|---|
| **经营中心**（跨域） | 数据BI + 账号矩阵 | 经营大盘、账号矩阵(短视频号+电商店铺) | 跨域业务总览与跨域账号资产，不随 Tab 切换 |
| **AI 中心** | 技能中心 + 能力网关 + 工作流 | 技能/提示词、能力开关、自动化编排 | AI 能力与自动化统一管理 |
| **系统管理** | 设置 + 团队权限 + 接入 + 基础设施 | 系统参数、成员/角色/租户、第三方接入、服务监控 | 平台后台管理 |
| **个人中心** | 个人中心 | 账号与偏好 | 用户级设置 |

> 融合后：跨域的「数据BI / 账号矩阵」进经营中心；AI 三件套（技能/网关/工作流）进 AI 中心；后台四件套（设置/权限/接入/基础设施）进系统管理；个人中心独立。所有原功能均保留、不丢失。

### 2.5 导航交互规则（沿用先前约定）

- **真实功能菜单，不是摆设**：左导航 / 通用栏每一项均可**手动点击直接进入对应模块页**（如点「选题中心」即进选题模块、「订单中心」即进订单页、「数据BI」即进 BI 页）。进入后可正常操作业务。
- **`@AI` 为附加快捷动作**：任一域项右侧 `@AI` 把该域任务直接丢进 AI 对话框，由 AI 调对应工具执行（映射见 2.2/2.3 末列）；是对「手动进入」的补充，而非替代导航。
- **导航与 AI 协同**：手动进模块做精细操作；`@AI` 做跨目录的端到端任务（如"做五粮液短视频挂车"会串起 内容创作→发布分发）。

## 三、第 2 段：AI 对话框（运营任务入口）

**角色**：运营任务的统一自然语言入口。用户在此"丢任务"，AI 经 Orchestrator(graph) 调运营工具执行。

| 能力 | 实现（对齐 SSE 事件） |
|---|---|
| 自然语言输入 | 文本框 + 快捷指令（@选题 / @脚本 / @直播中控 / @复盘） |
| 流式输出 | `text` 事件逐步渲染 |
| 工具进度可见 | `tool_start`（⏳正在执行X Agent）/ `tool_result`（✅/❌） |
| 富结果 | 脚本大纲、视频草稿、订单卡片、复盘报告 |
| 确认卡片 | 命中人工闸（发布/投流/客诉/对账/选品）→ 渲染待审卡片（映射现有审核流程） |
| 多轮 | 工作记忆上下文连续 |
| 语音 | 移动端语音输入 |
| 错误 | `error` 事件红色告警 + 建议 |

- **示例指令**：「给红星商行做条五粮液短视频，挂车卖」「把上周退货率高的 SKU 拉个复盘」「双11 投流预算 5 万，跑千川」

## 四、第 3 段：工作区（运营数据总览 + 任务标签）

**角色**：默认即运营数据总览，进入系统**无需开启任何页面**；执行任务时开启**新页签直接覆盖**，多任务以标签切换。

### 4.1 默认态：运营数据总览（进入即见，不开任何页面）

| 区块 | 内容（运营数据，实时） |
|---|---|
| 概览卡 | 选题库数 / 待拍脚本 / 直播在线数 / 今日订单 / 待审工单 / 待复盘项 |
| 实时看板 | 直播中控缩略大屏 / 订单趋势 / 投流消耗 / 内容发布状态 |
| 待办 | 待确认（发布/投流/客诉/对账/选品）+ 待复盘任务，点击即进对应确认/复盘 |
| 快捷丢任务 | 顶部 `@选题` `@脚本` `@直播中控` `@复盘` 直接把任务丢给 AI |

- 工作区默认就是运营主页：数据总览、看板、待办一目了然，**不需要点开任何子页面**才看到运营数据。

### 4.2 任务态：开启新页签，直接覆盖，采用标签

| 行为 | 表现 |
|---|---|
| 触发 | 对话框丢任务 / 导航模块内「丢给 AI」/ 点击待办项 → **开启新页签** |
| 覆盖 | 新任务页签**直接覆盖**当前工作区视图（默认总览被盖在底层） |
| 标签栏 | `[运营总览]  [五粮液短视频·进行中]  [双11投流·待确认]`——每个任务一个标签，可切换/关闭 |
| 任务页签内容 | 步骤流（选题→脚本→成片→分发→直播→复盘，节点高亮）+ 工具面板（对应 `tool_start/result`）+ 产物区（脚本/视频/订单/直播大屏/复盘，可微调）+ 确认区（审核卡片） |
| 关闭标签 | 关闭任务标签 → 回到默认「运营总览」，数据不丢 |

- **视频运营 vs 电商运营产物差异**：视频侧偏脚本/素材/直播大屏；电商侧偏选品看板/订单台/对账表。任务页签按当前 Tab 呈现对应产物模板。
- **与对话框边界**：对话框=说与看结果；工作区=默认看运营数据 + 任务执行页签（看过程、改产物、批确认）。AI 执行时对话框与工作区标签联动（同 sessionId）。

## 五、三段协同流程（运营示例）

```
用户进入运营系统 → 工作区默认即「运营总览」（数据/看板/待办，无需开任何页面）
   │
   ▼ 在对话框：「给红星商行做条五粮液短视频，挂车卖」
Orchestrator(graph)：选题→脚本→成片→分发(挂车)
   │  开启新页签 **直接覆盖** 默认总览；标签栏新增 [五粮液短视频·进行中]
   ▼  tool_start/result 实时推送至该任务页签
任务页签：步骤流高亮；产物区出现脚本大纲 + 视频草稿
   │
   ▼ 分发节点命中"发布"确认点
任务页签/对话框：弹出待审卡片（映射审核流程）
   │
   ▼ 用户批准（现有审核流程回调）
Orchestrator 续跑：挂车 + 发布 → done
   │
   ▼
对话框：✅ 已发布，链接；任务页签：产物定稿；复盘 Agent 回流优化
   │
   ▼ 关闭标签 → 回到「运营总览」
```

## 六、与管理系统 AI 助手 UI 的关系

| 项 | 管理系统 AI 助手（已实现） | 运营系统 UI（本设计） |
|---|---|---|
| 范式 | 三段（导航/对话框/工作区） | 同三段范式 |
| 导航栏 | 通用账号/租户/会话上下文 | 运营域导航（视频/电商双板 + 通用栏），**每项可手动点击进入模块** |
| 对话框 | 通用任务（权限/主数据…） | 运营任务（选题/脚本/直播/订单/复盘…） |
| 工作区 | 通用执行面（需进页才见） | **默认运营数据总览**（进入即见，不开页面）+ 任务新页签直接覆盖 + 标签切换 |
| 引擎 | 同一 AI 底座（:3016 完善后复制到运营实例） | 同一底座，systemScope=ops，内嵌运营本地包，**共用总后台**接运营微服务（前期不独立部署服务器） |

> 两套 UI 共用同一 AI 底座引擎；差异仅在导航内容、接线微服务、产物模板——印证"全量开放 + 复制部署"路线。

## 七、响应式与端点

| 端 | 三段呈现 |
|---|---|
| Web 端（PC 工作台） | 导航栏(顶Tab+左导航+通用栏，可点进模块) + AI对话框(浮动/停靠) + 工作区(默认运营总览主区 + 任务标签覆盖) |
| 移动端(H5/App) | 底部「AI助手」Tab → 对话框(全屏) + 工作区(下方) |
| 管理端 | 运营配置页 + AI 用量统计 |

- SSE 事件（`text/tool_start/tool_result/done/error`）统一驱动对话框与工作区渲染（沿用 v2.0 `AISSEClient`）。
- 小程序不接入 AI（沿用既有决策）。
