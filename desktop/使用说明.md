## 真实对接了什么
| 功能 | 对接接口 | 说明 |
|---|---|---|
| 登录 | `POST {认证中心}/api/admin/auth/login` | 用管理系统账号登录，拿商家 JWT（issuer=zhixiang-system，与 AI 底座验签配置对齐） |
| 对话 | `POST {AI底座}/api/chat`（SSE 流式） | 真实 Agent Loop：text 增量文本 / tool_start / tool_result 时间线 / clarify 澄清 / done(usage) / error |
| 写确认卡 | SSE `pending_write`/`await_confirm` 事件 | 按 preview（operation/summary/details）渲染卡片 + 按 expireAt 倒计时 |
| 确认执行 | `POST /api/chat/confirmations/:id/confirm` | 处理 success / needsSecondConfirm（高危二次确认）/ operationId 撤销提示 |
| 取消 | `POST /api/chat/confirmations/:id/cancel` | |
| 启动提醒 | `GET /api/chat/confirmations` | 登录后拉取待确认写操作，主动渲染确认卡 |
| 模型切换 | `GET /api/chat/models` | 设置抽屉「模型」段，点击切换（glm/deepseek/ollama/外部模型） |

默认地址：AI 底座 `https://saas.onepan.cn/ai-api`，认证中心 `https://api.onepan.cn`（均可在设置抽屉改，支持内网 IP）。

## 运行
```powershell
cd D:\Users\ZXQL\ZXQL-AI\desktop
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
npm install --registry=https://registry.npmmirror.com
npm start
```
- 浏览器直接打开 `app/index.html` 也能用（窗口钮降级为提示、有模拟窗口壳）
- Electron 里是真无边框：无系统标题栏、顶栏拖动、右上角自绘三钮

## 安全说明
- JWT 仅存本机 localStorage，不落任何第三方；对话链路：桌面端 → AI 底座（JWT 鉴权）→ 业务后端（authToken 透传）
- 写操作强制确认（R70-15），高危工具需二次确认，全程审计留痕

## 边界（当前版本）
- 会话列表为本地保存（标题=首条消息），历史消息本地重放；服务端上下文靠 conversationId 续聊
- 晨报等主动推送暂无对应后端接口，未做（后端就绪后在 pullPending 处扩展）
