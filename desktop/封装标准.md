# 智享全链 · 桌面端封装标准 v1.0

> 2026-09-05 确立。**所有后续桌面端封装一律按本标准执行。**
> 首个标准实现：`desktop/`（智享AI 桌面客户端）。

## 一、目录结构（固定）
```
<project>-desktop/
├── app/index.html      客户端页面（设计稿 100% 保留 + 真实对接层；禁止改动原稿布局样式）
├── main.js             frame:false 无边框 + file:// 去 Origin 防 CORS
├── preload.js          contextBridge 桥（窗口控制）
├── build/icon.ico|png  品牌 Logo 生成的应用图标
├── package.json        含 electron-builder build 配置
├── 使用说明.md          运行/打包/产物/对接契约
└── release/            产物（不入库）
```

## 二、双产物（必选）
| 产物 | 命名 | 用途 |
|---|---|---|
| NSIS 安装包 | `<产品名>-安装包-${version}.exe` | 正式分发：可选目录、桌面+开始菜单快捷方式 |
| 便携版 | `<产品名>-便携版-${version}.exe` | 免安装单文件，双击即用 |

## 三、无边框窗口规范（Codex 风格）
1. `main.js`：`frame:false`；`onBeforeSendHeaders` 删除 `file://` Origin。
2. 顶栏 = 自绘标题栏：`-webkit-app-region:drag`（按钮 no-drag）。
3. 右上角自绘三钮（— □ ✕，关闭 hover 红）→ preload 桥 → 系统窗口 API；浏览器预览降级 toast。
4. `body.native` 区分实机/预览：实机去模拟壳；浏览器给暗背景+12px 圆角窗口壳。

## 四、图标规范
品牌 Logo（圆框版 `D:/Users/图片/logo-refine-a.jpg`）→ Pillow 居中裁剪 + 白底 12% 圆角 → `icon.ico`（256/128/64/48/32/16）+ `icon.png`。禁止默认 Electron 图标。

## 五、镜像环境变量（必设）
```powershell
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
$env:ELECTRON_BUILDER_BINARIES_MIRROR = "https://npmmirror.com/mirrors/electron-builder-binaries/"
npm install --registry=https://registry.npmmirror.com
npm run dist
```
教训：不设镜像走 GitHub 会卡死（实测 17 分钟无进展；带镜像 1 分钟）。长命令重定向日志，勿用管道 tail。

## 六、真实对接规范
1. 先读后端源码确认契约（含 SSE 全部事件类型与字段名），禁止凭想像、禁止造假数据。
2. 身份只认 JWT（主后端 `/api/admin/auth/login` 签发，issuer=zhixiang-system/audience=zhixiang-client）。
3. SSE 事件：text/tool_start/tool_result/pending_write/clarify/done/error 全解析；写确认卡含 expireAt 倒计时、needsSecondConfirm 二次确认、operationId 撤销提示。
4. 交付前用测试 JWT（服务器共享 SECRET 手写 HS256）curl 打真实链路验证。
